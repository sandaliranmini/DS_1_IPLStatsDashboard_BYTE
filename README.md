# IPL Cricket Statistics Dashboard

Interactive dashboard for analyzing IPL team and player performance (2008-2025).

---

## Data Source
- **Source:** Kaggle IPL Complete Dataset (Enhanced Edition)
- **URL:** https://www.kaggle.com/datasets/meruvakodandasuraj/ipl-complete-dataset-2008-2025-enhanced-edition
- **Extraction Date:** 2026-09-05
- **Files Used:** `matches.csv`, `deliveries.csv`

---

## How to Run

### Prerequisites
- Python 3.8 or higher
- pip (Python package manager)

### Installation

1. **Download the dataset** from Kaggle
2. **Clone or download** this repository
3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the dashboard:** 
   ```bash
   python -m streamlit run dashboard.py
   ```
5. **Open your browser and navigate to the URL shown in the terminal**
